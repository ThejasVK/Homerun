# Thejas Vijaykumar Koiloorkar: portfolio

Personal site: https://thejasvk.github.io/Homerun/

A single static page (HTML and CSS, no build step, no JavaScript) with projects, experience, education, skills and contact details. It follows the visitor's light or dark setting, works at phone width, and respects reduced-motion settings.

To update: edit `index.html` or `styles.css` and push to `main`. GitHub Pages redeploys in about a minute. Bump the `?v=` value on the stylesheet link so returning visitors get the new styles.
