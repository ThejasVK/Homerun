Selected projects

guestgraph

Identity resolution and audience activation for restaurant transaction data. Most guests pay with a card and never scan a loyalty ID; guestgraph links those anonymous visits to real guests and turns them into audiences a marketer can use.

  • Union-find identity graph over loyalty profiles, card tokens and receipt emails, with a guard that stops shared cards from merging strangers (99.9% purity against ground truth).
  • Audience segments in SQL, uploaded to Meta and Google as hashed identifiers with batching and retry on rate limits.
  • Holdout-based lift measurement with a significance test and a sample-size check, plus a small API, an AWS Lambda deployment template and CI.

Python, SQL, DuckDB, AWS Lambda, GitHub Actions

AgentGuard

A log-triage AI agent built to handle untrusted input: guardrails for prompt injection and data exfiltration, card-number masking, a tamper-evident audit log, and red-team tests that fail the build if an attack gets through.

Python, LLM agents, Amazon Bedrock, OWASP LLM Top 10

AWS VPC with Terraform

A multi-AZ network as reusable Terraform modules: public and private subnets, NAT, flow logs to CloudWatch, an S3 endpoint and a bastion reached through SSM. Formatted, validated and linted in CI.

Terraform, AWS, networking
